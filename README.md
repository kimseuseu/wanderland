# WANDERLAND — 낙원 하이브

Once Human 게임 클랜 **낙원 하이브** 공식 웹사이트

## 기능

- **장비 빌드** — 무기/모듈/방어구/접미사 등 세부 빌드 공유 & 탐색
- **게임 지도** — 클릭으로 핀 추가, 위치별 메모 공유
- **하이브원** — 멤버 관리 (낙원가이드/베테랑사원/신입사원/휴직)
- **블랙리스트** — 주의 유저 닉네임/UUID/부캐/사건 기록

## 기술 스택

- **Next.js 14** (App Router)
- **React 18**
- **Paperlogy** + **Pretendard** 커스텀 폰트
- **JetBrains Mono** (모노스페이스)

## 실행

```bash
npm install
npm run dev
```

http://localhost:3000 에서 확인

## 빌드 & 배포

```bash
npm run build
npm start
```

Vercel 배포 시 `npm run build` 자동 실행
